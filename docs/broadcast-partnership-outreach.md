# QueensArena broadcast partnerships

Objetivo: criar uma camada profissional "Onde ver" com grelhas, links oficiais e possíveis parcerias editoriais/comerciais.

Páginas úteis:

- Contactos: https://www.sporttv.pt/contactos/
- Parcerias: https://www.sporttv.pt/parcerias/
- Site: https://www.sporttv.pt/

Assunto sugerido:

```text
Parceria QueensArena x SPORT TV | desporto feminino e informação de transmissão
```

Email/mensagem:


## Notas operacionais

- Não importar grelhas de TV por scraping sem autorização.
- Mostrar "confirmar na grelha oficial" até existir acordo formal.
- Guardar qualquer autorização por escrito antes de automatizar dados de transmissão.
- Separar dados desportivos de dados de transmissão: resultados vêm de fontes desportivas; "Onde ver" vem de canais/plataformas.
