# QueensArena - pedido de colaboração para dados oficiais

## Quem somos

A QueensArena é uma aplicação dedicada ao desporto feminino. O objetivo é tornar calendários, resultados, classificações, equipas, atletas e competições mais fáceis de encontrar, com fontes oficiais identificadas e uma experiência simples para adeptos, clubes, atletas e media.

URL pública: https://queensarena-next.vercel.app

## O que estamos a pedir

Queremos trabalhar com federações portuguesas para apresentar dados oficiais ou autorizados. O pedido prioritário é um destes caminhos:

- API oficial, feed JSON/XML/CSV, ficheiro regular ou endpoint técnico;
- acesso media/digital/data partnership;
- autorização escrita para recolha estruturada de páginas oficiais, respeitando limites técnicos, cache, atribuição e condições de utilização;
- contacto correto do departamento responsável por competições, dados, informática, comunicação digital ou parcerias.

## Dados pretendidos

- Competições: nome oficial, modalidade, país/região, época, escalão, género e estado.
- Jogos: data, hora, local, jornada/fase, equipa casa, equipa fora, resultado, estado e link oficial.
- Classificações: posição, equipa, jogos, vitórias, empates, derrotas, pontos, golos/pontos marcados e sofridos.
- Equipas: nome oficial, clube, país, modalidade, competição/época, links oficiais e logótipo quando autorizado.
- Atletas: nome, equipa, nacionalidade, posição, número e estatísticas quando disponíveis e autorizado.
- Metadados: fonte, URL oficial, data de atualização, cobertura e limitações conhecidas.

## Garantias da QueensArena

- A app não é uma plataforma de apostas.
- As fontes oficiais aparecem identificadas na aplicação.
- Os dados são guardados com referência de origem, data de sincronização e estado de qualidade.
- O tráfego para páginas oficiais pode ser limitado com cache, sincronizações agendadas e respeito por robots/termos quando aplicável.
- Dados de atletas menores ou informação sensível só devem ser usados quando forem públicos, necessários e permitidos pela fonte oficial.

## Modalidades prioritárias

1. Futebol, futsal e futebol de praia feminino.
2. Andebol e andebol de praia feminino.
3. Voleibol e voleibol de praia feminino.
4. Basquetebol e 3x3 feminino.

## Resposta pretendida

Idealmente, precisamos de saber:

- se existe feed/API oficial ou ficheiro de dados;
- se existe custo, contrato ou procedimento de autorização;
- se podemos usar páginas oficiais como fonte estruturada;
- que texto de atribuição/logótipo/link devemos mostrar;
- quem deve ser o contacto técnico para testes.
